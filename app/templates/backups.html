FULL SERVER MIGRATION

بکاپ و ریستور کامل IronPanel

بکاپ جدید برای انتقال واقعی به سرور دیگر ساخته می‌شود: Snapshot سازگار دیتابیس، همه کاربران و مصرف‌ها، ادمین‌ها و نماینده‌ها، تنظیمات و دامنه/ساب، Tokenها، پروفایل‌ها و هویت کامل پروتکل‌ها مثل OpenVPN PKI و tls-crypt، کلید WireGuard، SSL/Let's Encrypt، Ocserv، L2TP/IKEv2، Xray و Hysteria2.

مهم: این فایل شامل کلیدهای خصوصی و Secretهای سرور است. فقط مدیر اصلی باید به آن دسترسی داشته باشد. بعد از انتقال، DNS دامنه‌های قبلی باید به IP سرور جدید اشاره کند تا کانفیگ‌های قبلی بدون تغییر به سرور جدید برسند.

ریستور روی سرور جدید

اول همین نسخه یا نسخه جدیدتر IronPanel را روی سرور مقصد نصب کن، سپس فایل بکاپ را اینجا Restore کن. دیتابیس و Identityهای قبلی حفظ و Runtime با همان کلیدها بازسازی می‌شود.

دستور ترمینال

بکاپ CLI نیز دقیقاً از همین موتور Migration استفاده می‌کند:

cd /opt/ironpanel && sudo /opt/ironpanel/.venv/bin/flask --app run.py safe-backup

Auto Backup و Admin Bot هم از همین فرمت کامل استفاده می‌کنند؛ برای کاهش حجم، سورس برنامه در بکاپ‌های دوره‌ای تکرار نمی‌شود.
