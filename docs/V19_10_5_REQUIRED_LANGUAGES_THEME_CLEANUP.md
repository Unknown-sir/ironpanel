# IronPanel v19.10.9

This release removes the automatic/system theme option and limits theme selection to Light and Dark.

It also adds the required language set for the panel: English, Arabic, Chinese, French and Persian. The legacy language bridge now covers rendered HTML, placeholders, button values, helper text, guide text and client-side messages so Persian UI literals do not leak into non-Persian languages.

The mobile drawer stylesheet fix is bundled into the full project package.
