# v19.9.27 - Professional Office UI Redesign

This release replaces the previous playful redesign layer with a more formal administrative interface.

## Design updates

- One-column login page suitable for operational/admin environments.
- Neutral office color palette with clear light/dark theme behavior.
- Responsive RTL/LTR-safe sidebar drawer for mobile screens.
- Standardized section names, menu grouping, spacing, form controls, cards, buttons and tables.
- Dashboard rebuilt around operational KPIs, service state, resource metrics and common actions.
- Global table wrappers and form/card styles keep all pages stable on small screens.
- Emoji-heavy menu labels were replaced with compact office badges and clearer Persian labels.

## Compatibility

No feature was removed. This release only updates UI templates/CSS and keeps all prior fixes from v19.9.24-v19.9.26, including hot user sync for nodes and Telegram bot access handling.
