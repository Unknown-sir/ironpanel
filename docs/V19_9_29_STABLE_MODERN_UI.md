# v19.9.29 Stable Modern UI & Menu Fix

This release replaces the confusing experimental navigation layer with a stable, modern, enterprise-style UI layer.

## Highlights
- Fixed mobile drawer button not opening the sidebar.
- Rebuilt sidebar behavior with explicit details/submenu rendering.
- Closed submenus no longer leak their links into the main menu.
- Added stable accordion behavior and active-section auto-open.
- Added a neutral office design system for cards, tables, forms, buttons, topbar, login, RTL/LTR and dark/light theme.
- Reduced visual noise while keeping all panel features and routes intact.
