# v19.9.28 - Complete UI Redesign

This release replaces the color-only UI refresh with a full responsive design system for IronPanel.

## Scope
- New professional login screen.
- New application shell with grouped sidebar navigation.
- New responsive topbar and mobile drawer.
- Rebuilt dashboard sections and KPI layout.
- Global design rules for cards, forms, tables, buttons, logs and action bars.
- Safer mobile table wrappers through app.js.

## Compatibility
All existing routes, templates and backend features are preserved. The redesign is implemented with base template updates and a design-system override layer so existing page content is not removed.
