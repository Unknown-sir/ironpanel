# IronPanel v19.9.28 - Formal Admin UI Redesign

This release replaces the previous colorful/experimental interface with a more formal, office-grade admin design system.

## Highlights

- One-column professional login page.
- Clear sidebar information architecture with daily operations, system management, business/access, and security sections.
- Reduced emoji usage and clearer naming for RTL and LTR languages.
- New dashboard layout focused on decision-making: KPIs, resources, service status, and common actions.
- More consistent cards, tables, forms, buttons, code blocks, toasts, spacing, borders, and typography.
- Responsive drawer navigation for mobile and tablet.
- Light/dark theme variables and RTL/LTR-safe spacing.

No operational capability was removed.
